# Reel files

Drop the project videos here, named to match `components/deployments.data.js`:

    fraud-detection.mp4    fraud-detection.jpg
    clinical-copilot.mp4   clinical-copilot.jpg
    underwriting.mp4       underwriting.jpg
    compliance.mp4         compliance.jpg

Encode: H.264 / MP4 (Safari won't play VP9 inline), ~1280px wide, 25-60s,
under ~6MB each. No essential audio — the reel autoplays muted, and most
people will never unmute it.

The `.jpg` poster is what shows before playback and on slow connections, so
pick a frame that reads at a glance.

Until a file exists, the stage shows an empty state naming the path it wants.
